DEPLOYMENT / RELEASE

LƯU & XUẤT BẢN

Đưa thay đổi từ máy của bạn lên website công khai.

01

LƯU BẢN NHÁP TRÊN MÁY

Bản nháp được lưu trong trình duyệt hiện tại. Khi mở website bằng cùng địa chỉ Live Server trên máy này, trang chủ sẽ đọc bản nháp đó.

02

XUẤT FILE DỮ LIỆU

Tải xuống file content.json mới. Đây là file chứa sản phẩm, giá, ảnh, banner và thông tin liên hệ.

03

CẬP NHẬT GITHUB PAGES

  1. Mở repository GitHub của website.
  2. Thay file content.json cũ bằng file vừa tải.
  3. Nếu thêm ảnh hoặc file tải mới, tải cả các file đó vào đúng thư mục assets/.
  4. Commit changes và đợi GitHub Pages cập nhật.
MỞ GITHUB ↗
Quan trọng về bảo mật và quyền quản trị

Vì website đang dùng GitHub Pages (hosting tĩnh), trang quản trị này không có đăng nhập an toàn và không thể tự ghi file lên GitHub. Bất kỳ ai biết đường dẫn /admin.html đều có thể mở giao diện quản trị trên trình duyệt của họ, nhưng các thay đổi chỉ nằm trên máy của họ cho đến khi bạn tự xuất file và cập nhật repository. Muốn có tài khoản admin thật, phân quyền và lưu dữ liệu trực tuyến cần backend hoặc CMS có xác thực.
